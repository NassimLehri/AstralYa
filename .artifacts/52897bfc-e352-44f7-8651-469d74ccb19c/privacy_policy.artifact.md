# Politique de Confidentialité d'Astralya

Cette politique de confidentialité décrit comment vos informations personnelles sont collectées, utilisées et partagées lorsque vous jouez à **Astralya : Les Gardiens du Néant**.

## 1. Collecte des Données
Nous ne collectons aucune donnée personnelle identifiable (nom, adresse, email, etc.) via l'application. Le jeu fonctionne entièrement hors-ligne.

## 2. Stockage des Données
Toutes les données de jeu (sauvegardes, progression, inventaire) sont stockées localement sur votre appareil. Si vous désinstallez l'application, ces données seront supprimées.

## 3. Autorisations Android
L'application peut demander les autorisations suivantes :
- **Vibration** : Pour les effets haptiques en combat.
- **Wake Lock** : Pour empêcher l'écran de s'éteindre pendant les cinématiques.
- **Stockage** : Pour sauvegarder votre progression sur votre appareil.

## 4. Services Tiers
Le jeu n'utilise aucun service publicitaire ou d'analyse tiers (Analytics) qui collecterait des données sur votre comportement.

## 5. Modifications
Nous nous réservons le droit de mettre à jour cette politique. Toute modification sera reflétée par une mise à jour de l'application.

## 6. Contact
Pour toute question concernant cette politique, vous pouvez contacter le développeur à l'adresse associée à la fiche Google Play.
